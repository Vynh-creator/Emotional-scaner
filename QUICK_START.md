# 🚀 Быстрый запуск Emotional Scanner

## ✅ Что работает сейчас:
- **Эмоциональный анализ по видео** - основная функция работает отлично
- **Обнаружение лиц** - работает в реальном времени
- **Анализ вовлеченности** - работает стабильно
- **Захват аудио** - работает без переполнений
- **GUI интерфейс** - работает плавно

## ⚠️ Что требует доработки:
- Некоторые модели (vitals, audio, pupil) не загружаются из-за проблем с путями
- Это не влияет на основную функциональность распознавания эмоций

## 🚀 Запуск приложения:

### Вариант 1: Быстрый запуск
```bash
python run.py
```

### Вариант 2: Запуск через модуль
```bash
python -m src.main
```

## 🎯 Использование:

1. **Запуск приложения** - Используйте `python run.py`
2. **Начало записи** - Нажмите "🔴 Начать запись"
3. **Анализ в реальном времени** - Приложение будет анализировать эмоции
4. **Просмотр результатов** - Результаты появляются в текстовом поле

## 🔧 Оптимизации производительности:

- **30 FPS** - Оптимальная частота кадров
- **Минимальные буферы** - Предотвращают накопление данных
- **Быстрая загрузка** - Модели загружаются последовательно
- **Стабильная работа** - Нет отставания от реального времени

## 🎮 Управление в GUI:

- **🔴 Начать запись** - Начать анализ эмоций
- **⏹️ Остановить** - Остановить запись
- **Размер чанка** - Интервал анализа (1-10 секунд)
- **▶️ Просмотреть** - Просмотреть последний фрагмент

## 💡 Советы:

1. **Хорошее освещение** - Для лучшего распознавания лиц
2. **Стабильная камера** - Для точного анализа
3. **Тихая обстановка** - Для качественного аудио анализа

## 🐛 Если что-то не работает:

1. **Проверьте камеру** - Убедитесь что камера подключена
2. **Перезапустите приложение** - Иногда помогает перезапуск
3. **Проверьте консоль** - Там будет информация об ошибках
